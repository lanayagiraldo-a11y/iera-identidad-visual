# IERA — Identidad Visual y Skill de Marca/Voz/Campañas

Manual de identidad visual de **IERA** (wordmark "iera" con rombo multicolor sobre la "i") y el skill de marca/voz/campañas que lo acompaña.

## Contenido

- `iera-identidad-visual.html` — manual de identidad visual (arquetipo, paleta de colores, tipografía, tono de voz, aplicaciones). Abre directo en el navegador.
- `IERA-Skill-Marca-Voz-Campanas.md` — skill en Markdown con las reglas de marca, voz y manejo de redes sociales de IERA (incluye guías de comunicación en redes: manejo de comentarios, escalamiento a Outreach Specialists, política de no discriminación, etc.)

## Cómo instalarlo

### Claude Code / Claude (Anthropic)
1. Copia `IERA-Skill-Marca-Voz-Campanas.md` a tu carpeta de skills (por ejemplo `~/.claude/skills/iera-marca-voz-campanas/SKILL.md`).
2. El archivo ya trae el formato de skill (frontmatter + secciones); Claude lo carga automáticamente cuando el tema coincide.

### ChatGPT / Otros asistentes
1. Sube `IERA-Skill-Marca-Voz-Campanas.md` como archivo de conocimiento/contexto del proyecto o pégalo como instrucciones personalizadas.
2. Usa `iera-identidad-visual.html` como referencia visual — ábrelo en el navegador para ver paleta, tipografía y tono de voz.

### Como referencia humana
Simplemente abre `iera-identidad-visual.html` en cualquier navegador. Es un documento visual standalone, no requiere instalación.
